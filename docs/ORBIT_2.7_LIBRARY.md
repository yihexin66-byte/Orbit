# Orbit Learn 2.7：唐诗三百首、高中 3500 词与可隐藏的助手球

2.7 把 2.6 的「三本书」从演示条目升级为两本真正能翻的书：唐诗选扩展为 **309 首《唐诗三百首》**，英语词卡扩展为 **3,877 条高中 / 高考词汇**。同时给首页 AI 助手球补上「躲开内容」的行为：默认位置常亮，拖到别处降为半透明，靠近屏幕边缘进一步变淡，触摸或拖动时恢复全不透明。版本 `2.7.0`（versionCode 9），包名仍为 `com.example.orbit`。

本次不新增网络请求、不改 `/api/ai/*` 契约、不触碰 Coze 凭证；两本书仍然完全离线，点「AI 讲解 / 让 AI 讲讲」时才走已有的云函数。数学讲义、目标、规划、成长、账号与同步均未改动。

## 1. 数据接入

### 1.1 古诗：309 首

古诗数据来源为公开的《唐诗三百首》整理稿（309 首，全部为唐代）。每条保留：

| 字段 | 用途 |
| --- | --- |
| `id` | `tang-<poemid>`，列表 key 与「今日」定位 |
| `title` / `author` / `dynasty` | 卡片标题与作者行 |
| `lines` | 正文按行拆分，最多 60 行（《长恨歌》） |
| `note` | 注释；3 首为空 |
| `appreciation` | 赏析；11 首为空 |

原 12 首演示诗不再硬编码，全部由数据文件提供；`静夜思`、`长恨歌`、`琵琶行` 等都在集合内。原 `LearningLibrary.poemFor(epochDay)` 的按天取模逻辑保留，只是分母从 12 变成 309。

### 1.2 英语：3,877 条

词表来源为公开高考 3500 词表。原始数据 3,893 条，规范化并去重后保留 **3,877 条**：

- 同名条目只保留首次出现的词条；`AD` 与 `ad` 按大小写视为两条。
- 名称中的私人区字符与音标重音符号做最小修正（如 `oˈclock` → `o'clock`）。
- 释义取 `trans` 数组，用「；」连接；音标优先美音。
- 词表包含少量短语与词形变化（如 `according to`、`arise arose arisen`），因此条数高于 3500。
- 42 条没有音标，卡片会显示「高中 3500 词」作为眉题，不显示空音标行。
- 原 18 个学习主题词中，只有 `focus`、`interval`、`reflect`、`confident` 在词表内，保留其例句与记忆提示；其余词条没有例句 / 提示，展开时显示「暂无例句与记忆提示，点下方按钮让 AI 生成一个高考语境例句。」

`EnglishWord.example / exampleZh / tip` 改为带默认值的可选字段，卡片与首页预览均做空值条件渲染。

### 1.3 打包方式

数据不再写进 Kotlin 字面量，而是放在：

```text
app/src/main/resources/learning/poems.json   1,446,194 bytes
app/src/main/resources/learning/words.json     536,978 bytes
```

`LearningLibrary` 通过 `ClassLoader.getResourceAsStream` 读取，Gson 反序列化后 `lazy` 缓存。`OrbitApplication` 在启动时用一个 daemon 线程调用 `LearningLibrary.warmUp()`，把约 2 MB 的解析放到登录页 / 冷启动后台，首页第一帧不承担解析开销。资源同时位于 JVM 测试 classpath，因此单元测试不需要 Robolectric。

> 数据为公开数据集整理，用于作品集离线演示；若要商业发布，需自行复核数据授权与释义准确性。

- 首页「今日学习」与书架继续共用同一套 `LearningLibrary`；书名变为 **唐诗三百首**、**高中 3500 词**，数学讲义不变。
- 书架数量动态显示：`309 篇`、`3877 词`、`18 个`。
- 书页副标题同步更新；「打开唐诗三百首，共 309 篇」「打开高中 3500 词，共 3877 词」仍作为无障碍描述。
- 长诗折叠：未展开时正文最多 4 行，超出以省略号收束；展开后显示全文、注释与赏析。这样《长恨歌》不会再让一张折叠卡片占据整屏。
- 注释 / 赏析为空时不渲染对应标题与段落，只保留正文与「让 AI 讲讲」。
- 英语卡：音标为空时用「高中 3500 词」代替眉题；例句、译文、记忆提示分别按空值隐藏；长词头允许两行。

- 数学讲义与「年级 chip」、每日一句、星轨、目标等均保持 2.6 行为。

## 3. 助手球的半透明规则

`AiAssistantFabVisibility` 把视觉规则做成纯函数，Compose 只负责动画：

| 状态 | 静止透明度 |
| --- | --- |
| 在默认右下角（允许 12dp 误差） | 1.00 |
| 已拖离默认位置，但离四边都超过 36dp | 0.55 |
| 已拖离默认位置，且距任一边 ≤ 36dp | 0.32 |
| 正在拖动 / 手指按住 | 1.00（临时覆盖） |

- 透明度用 `animateFloatAsState(260ms)` 过渡；按下时 `clickable` 的 pressed 状态会立即把球恢复为不透明。
- 默认位置坐标是 `maxFabX / maxFabY`（右下角，18dp 边距）；判定默认位置用 12dp 容差，避免轻微抖动就触发变淡。
- 边缘距离取 `min(x, y, maxFabX - x, maxFabY - y)`；默认位置虽然贴着右 / 下边，但因为仍是默认位置，保持常亮。
- 透明度只影响绘制，不拦截触摸：半透明状态下仍可轻触打开助手、按住拖动。
- 无障碍：`stateDescription` 在「常亮 / 半透明」之间切换，设备测试直接断言该语义。

这个行为不写盘；拖动位置仍由 `rememberSaveable` 保存，进程重启回到默认位置。旋转屏幕后位置会被重新钳制到新内容区边界。

## 6. 限制

- 数据是静态离线快照：没有搜索、收藏、生词本、学习进度或跨设备同步；「今日」只是按 epoch day 取模。
- 词表 3,877 条包含短语与词形变化，不是严格的 3,500 个单词；42 条缺音标，约 3,800 条没有内置例句与记忆提示，需要 AI 或后续补录。
- 唐诗的注释 / 赏析来自公开整理稿，3 首缺注释、11 首缺赏析；UI 会隐藏空块。
- 诗体排版是纯文本：不对仗、不竖排、不注拼音，长诗折叠为 4 行。
- 数据文件增加约 2 MB 未压缩资源（APK 内约 0.78 MB），首次解析由启动线程预热；低端设备冷启动仍可能多几十毫秒。
- 助手球半透明只按位置触发，没有「几秒无操作自动淡出」；默认位置刻意保持常亮，以免启动时找不到入口。
- 半透明状态不写入 Room / SharedPreferences；重启后球回到默认位置并恢复常亮。

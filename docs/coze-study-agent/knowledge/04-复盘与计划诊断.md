# 复盘与计划诊断

> 用途：当计划执行不下去时，先诊断原因，再改计划；不要用「自律不够」解释一切。

## 1. 周复盘的四个问题

1. **完成了什么？** 只看事实：计划数、完成数、完成率、学习任务数、习惯打卡、实际投入时间。
2. **哪里卡住了？** 具体到任务和时间段，不写「状态不好」这种结论。
3. **为什么卡住？** 从下面五类原因里选，不要混在一起：
   - 任务太大 / 太模糊；
   - 时间估计错误；
   - 方法不对（只输入没输出、只重复没反馈）；
   - 环境干扰（手机、噪音、通勤）；
   - 状态问题（睡眠、情绪、身体）。
4. **下周只改哪一件事？** 一个动作 + 一个验收标准；不要一次改五件事。

## 2. 复盘看哪些数据

| 指标 | 说明 | 怎么用 |
| --- | --- | --- |
| 完成率 | 完成数 / 计划数 | 连续两周 < 60%，先减量 |
| 学习任务完成 | 只统计 STUDY 类 | 区分「忙」和「学」 |
| 习惯打卡 | 实际 / 可能 | 看连续性，不追求满分 |
| 实际时长 | 计划 vs 实际 | 校准下一次估时 |
| 错题/错误类型 | 按类型统计 | 决定下一周练什么 |
| 精力 | 1–5 分 | 连续低分先减强度 |

## 3. 拖延诊断表

| 表现 | 可能原因 | 先做什么 |
| --- | --- | --- |
| 一直不开始 | 任务太大、不知道第一步 | 把任务缩到 10 分钟；只做第一步 |
| 开始了但总被打断 | 环境干扰、通知太多 | 手机放远；设 25 分钟专注块 |
| 学了很久没进展 | 方法不对、没有反馈 | 换成主动回忆/做题；找标准答案对照 |
| 总在最后一刻做 | 时间估计错误、逃避 | 提前设「最晚开始时间」；拆出中期检查 |
| 做完不想复盘 | 复盘太复杂 | 只记 3 行：完成率、卡点、下周一件事 |
| 一落后就想放弃 | 完美主义、补债心态 | 启动最小可行日；不补债，周末重排 |

## 4. 计划崩了怎么办

**第一步：停止补债。** 不要把所有未完成任务堆到明天；明天会再次崩。

**第二步：分三类处理。**

- 必须保留：直接服务阶段验收的任务；
- 可以缩水：做成最小可行版本；
- 可以删除：低优先级、重复、暂时用不上的任务。

**第三步：重排本周。**

- 每天最多 3 件关键任务；
- 至少留 1 个缓冲块；
- 给最难的任务安排在精力最好的时段；
- 明确「这周不做什么」。

**第四步：下周复盘时只验证一件事。** 例如「每天是否完成了 1 个最小任务」，而不是「是否全部完成」。

## 5. 过度计划的信号

- 计划表精确到每 15 分钟，但没有缓冲；
- 每天 5 件以上关键任务；
- 一周排满 7 天，没有休息；
- 同时开 3 个以上主线；
- 任务描述很长，但没有验收标准；
- 一落后就重做整张表。

处理：砍到 1 个主线 + 1 个维持任务；每天 3 件以内；先试跑一周再细化。

## 6. 状态不好时

- 先区分「累」和「不想」：累就休息，不想就缩小第一步；
- 连续失眠、食欲明显变化、持续情绪低落、无法集中注意力时，降低学习强度，并考虑寻求专业帮助；
- 不要用「再逼自己一下」解决持续的状态问题；
- 可以保留一个 10 分钟的维持任务，保持连续性，但不加码。

## 7. 调整规则模板

```text
如果连续 2 天未完成：
→ 启动最小可行日；周末重排；不补债。

如果一周完成率 < 60%：
→ 下周任务量减少 30%；只保留阶段验收任务。

如果一周完成率 > 90% 且精力正常：
→ 下周增加 10%–20%，优先加给薄弱点；不新增主线。

如果某个任务连续 3 次被推迟：
→ 拆成更小任务，或删除；不要继续原样保留。

如果某类错误重复出现：
→ 下一周安排一次专项练习 + 一次自测。
```

## 9. 复盘语气

- 对事不对人：说「任务太大」，不说「你太懒」；
- 先看数据，再看感受；
- 不夸大一次失败，也不粉饰；
- 每次只改一个变量，才能知道有没有效。

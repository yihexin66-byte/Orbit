# 学习科学核心方法

> 用途：给「Orbit 学习规划引擎」提供方法选择与执行建议。
> 原则：先判断任务类型，再选方法；方法服务于产出，不追求花哨。

## 1. 主动回忆（Retrieval Practice）

**是什么**：合上书，用自己的话写出或说出知识点，或做无提示自测。

**适合**：概念、定义、语言词汇、考试知识、错题复盘。

**怎么做**：
1. 学完一节，合书用 3 句话复述核心；
2. 当晚做 5 道无提示自测；
3. 把答错或卡住的点变成下一轮问题；
4. 第二天先回忆，再看资料。

**验收**：不看资料能说出核心概念，并能举一个例子。

**常见坑**：把重读、划重点、看答案当成回忆；看着答案说「我会了」。

## 2. 间隔重复（Spaced Repetition）

**是什么**：在遗忘前复习，而不是连续重复很多遍。

**基础节奏**：D1（次日）、D3、D7、D14、D30。材料越难间隔越短；越熟间隔越长。

**怎么做**：
- 用 Anki、记忆卡或错题本；
- 一张卡只考一个点；
- 到期先答，答不出再看答案；
- 连续两次答错，缩短间隔并补一个例子。

**验收**：到期卡片能独立答对；错题在两周后仍能解释。

**常见坑**：一天塞 200 张新卡，第二天放弃；卡片写成长段落，变成重读。

## 3. 交错练习（Interleaving）

**是什么**：把不同类型但相关的题目混着练，而不是一次只练一种。

**适合**：数学、物理、编程题、语言语法、考试选择题。

**怎么做**：
- 一次练习包含 2–3 种题型；
- 每道题先判断「这是哪类问题」，再解；
- 错题按类型归档，下次混入；
- 基础太差时先做少量示范题，再交错。

**验收**：看到题目能先分类，再选方法；混合测验正确率不低于分块练习。

**常见坑**：基础还没建立就强行交错，变成挫败；交错不是随机乱做。

## 4. 刻意练习（Deliberate Practice）

**是什么**：针对一个具体子技能，做略高于当前水平、能立刻得到反馈的练习。

**适合**：写作、口语、编程、乐器、实验操作、面试表达。

**怎么做**：
1. 把大技能拆成一个子技能（例如「SQL 联表查询」而不是「数据库」）；
2. 找 1–2 个示范或标准答案；
3. 练 15–30 分钟，立刻对照反馈；
4. 记录错误模式，下一轮只改一个点。

**验收**：子技能的错误率下降，或能在更短时间内完成同类任务。

**常见坑**：只重复已经会的内容；没有反馈，练了很久也不知道对不对。

## 5. 费曼技巧（Feynman Technique）

**是什么**：用外行能听懂的话解释一个概念，卡住的地方就是没懂的地方。

**适合**：理解抽象概念、准备讲解、面试复述。

**怎么做**：
1. 写下概念名；
2. 不用术语，向一个完全不懂的人解释；
3. 卡住就回到资料，补缺口；
4. 再用一个类比或例子重讲；
5. 最后压缩成 3 句话。

**验收**：能不用原文术语讲清「是什么、为什么、怎么用」。

**常见坑**：背定义；用更多术语解释术语。

## 6. 项目式学习（Project-Based Learning）

**是什么**：用一个可交付的作品带动知识学习。

**适合**：编程、设计、写作、课程设计、毕业设计。

**怎么做**：
- 先定义最小可交付版本（MVP）；
- 拆成 3–5 个里程碑，每个里程碑有可演示产出；
- 遇到不会的知识点，带着问题去学；
- 每个里程碑做一次自测或让别人试用。

**验收**：能演示、能解释关键取舍、能复现。

**常见坑**：一开始就做大而全；只跟着教程敲，不做自己的改动。

## 7. 认知负荷与时间块

**要点**：
- 一次只做一件事，避免边看视频边刷题；
- 新内容分块，每块 25–50 分钟，中间休息 5–10 分钟；
- 先看一个完整示范，再自己练；
- 难题和简单题交替，避免长时间卡死；
- 每天安排 1–2 个「深度块」，不要把所有时间切碎。

**常见坑**：把番茄钟当目标；休息时刷短视频，注意力没有恢复。

## 8. 睡眠、运动与记忆巩固

- 睡眠对记忆巩固很重要；考前通宵通常得不偿失；
- 每周保持规律运动，哪怕每次 20 分钟；
- 长时间学习后安排散步、拉伸或闭眼休息；
- 如果持续失眠、情绪低落或注意力明显下降，先降低学习强度，并考虑寻求专业帮助。

## 9. 常见误区

1. **学习风格匹配**：把学生分成「视觉型/听觉型」并匹配教学，证据并不稳定；更可靠的是按材料类型选方法。
2. **重读和划重点**：熟悉感不等于掌握；必须配合主动回忆。
3. **集中突击**：短期能记住，长期保持差；尽量分散到多天。
4. **只收藏不练**：收藏夹不是学习成果；每个资源配一个输出任务。
5. **计划越满越好**：没有缓冲的计划最容易崩；按 70%–80% 容量排。

## 10. 方法选择速查

| 任务类型 | 首选方法 | 配套动作 | 验收 |
| --- | --- | --- | --- |
| 背概念/名词 | 主动回忆 + 间隔重复 | 自测题、记忆卡 | 合书复述、到期答对 |
| 做题/考试 | 交错练习 + 错题归因 | 混合题组、错题本 | 混合测验正确率 |
| 语言输入 | 精听/精读 + 复述 | 影子跟读、摘要 | 能复述主旨和细节 |
| 语言输出 | 刻意练习 + 反馈 | 录音、批改、重写 | 错误率下降 |
| 编程/技能 | 项目式 + 刻意练习 | MVP、里程碑、Code Review | 能演示、能改 |
| 理解抽象概念 | 费曼 + 自测 | 讲解、类比、例子 | 不用术语讲清 |
| 长期保持 | 间隔重复 + 每周自测 | D1/D3/D7/D14/D30 | 两周后仍能答对 |

# 对话体验配置

## 1. 开场白

```text
我是 Orbit 学习规划引擎。告诉我你的目标、截止时间、当前基础和每周能投入的时间，我会给你一版能执行、能验收、能调整的计划。

如果信息还不全，也可以直接说「先按假设来一版」。
```

## 2. 预置问题（4 个）

```text
帮我规划 8 周通过四级，每天 60 分钟
每天只有 45 分钟，怎么安排最有效？
我连续三天没完成任务，帮我重排计划
推荐一套适合备考的复习方法
```

## 3. 建议问题 / 用户问题建议

- 对话版建议开启，最多 3 条，避免一次弹太多。
- 如果发现 API 调用返回的是建议问题而不是答案，关闭它；或让后端只取内容以 `{` 开头/包含完整 JSON 的 `answer` 消息。

## 4. 语音、快捷指令

- 语音：不需要，关闭。
- 快捷指令：可以不配；如果配，只放「生成计划 / 本周复盘 / 调整计划」三个，不要和开场白重复。

## 5. 对话体验检查

用下面这句话测试开场是否自然：

```text
我想在三个月内入门 Java 后端，但每天只有 90 分钟。
```

期望：先确认目标、基础、薄弱点和周末是否有更多时间，最多问 3 个问题；不要一上来甩一份 20 条任务的计划。

# Orbit Learn 2.6：书籍化学习库、数学讲义与可拖动交互

2.6 在 2.5 的「AI 学习助手 + 古诗 / 英语卡片」上继续加厚学习内容，并把首页的三处交互做得更顺手：学习资料从两列卡片变成**三本书的书架**，新增**初一至高三的数学讲义**；AI 助手悬浮球可以**拖到任意位置**；星轨节点可以**拖到另一条轨道**。版本 `2.6.0`（versionCode 8），包名仍为 `com.example.orbit`。

本次改动不新增网络请求，不改变 `/api/ai/*` 契约，也不触碰 Coze 凭证；所有资料继续离线内置，只有点「AI 讲解 / 让 AI 讲讲」时才走已有的云函数。

## 1. 真机问题：资料列表滑到底部后疯狂跳动

用户反馈在真机上把古诗 / 英语列表滑到底部后画面会持续抖动。原因来自两处叠加：

1. `ModalBottomSheet` 默认参与纵向拖拽。`LazyColumn` 到达底部后，剩余的向下手势会转交给弹窗本身的 sheet 锚点动画，列表内容跟着整张弹窗上下回弹。
2. 每张资料卡带有 `animateContentSize`。卡片展开 / 收起时高度动画与列表滚动在同一帧内反复测量，底部最后几张卡会互相挤动。

修复：

- `ModalBottomSheet(sheetGesturesEnabled = false)`：弹窗不再响应内容区的拖拽，只保留关闭按钮、返回键与遮罩点击；列表滚到底部就是终点，不再与整张弹窗抢手势。
- 移除资料卡的 `animateContentSize`：展开 / 收起改为即时布局，配合边框高亮与「＋ / －」状态，不再有高度动画参与测量。

设备验证不只看截图：`LearningVisualReviewTest` 会把古诗和英语列表分别滚到最后一项，等待稳定后截取书籍节点，再把 Compose 主时钟推进 1.2 秒并截第二帧，断言两帧**逐像素相同**。两本书都通过。

> 取舍：2.6 的底部弹窗不能下滑关闭。关闭入口仍有顶部「关闭」按钮、系统返回与点击遮罩。若后续恢复下滑关闭，需要同时处理列表到底部的嵌套滚动，否则抖动会回来。

## 2. 书籍化学习库

### 2.1 入口与结构

首页「今日学习」保留两张预览卡（今日古诗、今日英语），下方新增一条通栏**今日数学**条：∑ 图标、年级标签、标题与等宽字体公式，右侧是「AI 讲解」。点击预览卡直接进入对应书；点击「全部资料」进入书架。

书架为一页三本：

| 书 | 数量 | 封面说明 | 内容 |
| --- | --- | --- | --- |
| 唐诗选 | 12 篇 | 唐宋名篇 · 每日一首 | 静夜思、春晓、登鹳雀楼、望庐山瀑布、相思、江雪、悯农（其二）、竹石、咏柳、游子吟、题西林壁、观书有感（其一） |
| 英语词卡 | 18 个 | 学习主题词 | 学习主题词：perseverance、curiosity、deliberate、recall、consistency、insight、resilient、articulate、focus、retrieve、interval、prioritize、reflect、feedback、stamina、integrate、concise、confident |
| 数学讲义 | 18 个 | 初一至高三 | 6 个年级 × 3 个知识点，见第 3 节 |

书架底部还有一张 TODAY 卡，用一行文字串起今天的三样内容，并说明「每本书都可以逐条展开；展开后可以让 AI 讲解或出练习」。

### 2.2 书页

打开一本书后是一页 `LazyColumn`：

- 顶栏：返回书架、书名、数量与说明、关闭。
- 资料卡：标题、作者 / 音标 / 年级、正文；点击卡片展开注释、赏析、记忆提示或例题 / 答案 / 易错提醒，并出现「让 AI 讲讲」按钮。
- 数学书在顶栏下方多一行可横向滚动的年级 chip：初一、初二、初三、高一、高二、高三；切换后列表回到顶部，只显示该年级的 3 个知识点。
- 从书架打开数学书时，若今天的话题属于当前选中年级，会自动展开今日那张卡；从首页「今日数学」进入时则直接定位到今日话题。

「今日」徽标继续用于标记当天的古诗 / 单词 / 数学话题。

## 3. 数学讲义：覆盖初一至高三

每个年级 3 个知识点，共 18 个。每条包含标题、年级、摘要、公式、例题、答案与易错提醒，均可交给 AI 讲解或出练习。

| 年级 | 知识点 |
| --- | --- |
| 初一 | 有理数的加减、一元一次方程、二元一次方程组 |
| 初二 | 勾股定理、一次函数、二次根式化简 |
| 初三 | 一元二次方程、二次函数、锐角三角函数 |
| 高一 | 指数运算、对数运算、三角恒等变换 |
| 高二 | 等差与等比数列、导数与切线、直线与圆 |
| 高三 | 二项式定理、古典概型、导数求极值 |

公式用等宽字体渲染，支持上标字符（`aᵐ`、`x²`、`√`、`Σ` 等），窄屏会自然换行。年级选择状态用 `rememberSaveable` 保存，旋转屏幕不会丢。

## 4. 可拖动的 AI 助手悬浮球

2.5 的 58dp 助手球固定在右下角。2.6 允许在内容区内自由拖动：

- 手指按下即触发 `LongPress` 触感反馈，球体放大到 1.08、阴影从 12dp 提到 20dp；松开恢复。
- 位置以 `offset { IntOffset(...) }` 表达，坐标被钳制在内容区内，四周留 18dp；初始默认仍在右下角。
- 偏移用 `rememberSaveable` 保存，滚动列表、切换主题、旋转屏幕都不会跳回原点（进程重建后回到默认位置）。
- 点击与拖动共存：拖动超过触摸阈值不会触发打开对话，轻触仍然打开 AI 学习助手。
- 设备测试把球从右下拖到左上方，断言语义边界移动了至少 120px / 300px，再滚动首页并断言位置不变。

## 5. 星轨节点跨环拖动

2.5 的拖动只在原轨道内换位置，或者拖入核心完成任务。2.6 增加「换轨」：

- 拖动时节点半径跟随手指；释放时用 `OrbitLayout.nearestRing(radius)` 决定落到内环还是外环，分界线是两环半径的中点 `0.32 ×` 轨道宽度。
- 拖动过程中目标环会画出虚线圆：半径真正切换到另一条环时透明度 0.60，否则 0.22；跨环瞬间再触发一次 `TextHandleMove` 触感。
- 释放后按目标环的槽位重新吸附，并用与原逻辑相同的弹簧动画回到环上。
- `PlacementCache` 新增 `manualRings`：用户手动落到的环优先于「待完成在内、已完成在外」的默认规则，因此任务随后变成已完成、列表刷新或重组时不会被拉回原轨道。
- 拖入核心仍然优先于换轨：在核心半径内释放会完成任务，不改变手动环。

注意：轨道位置本来就是**只显示、不落库**的临时布局。`manualRings` 只在本次进程内有效，重启 App 后节点回到默认环；这与 2.5 的槽位摆放行为一致。

## 6. 首页文案与每日一句

- 「今日任务」改为「今日学习任务」；「今日习惯」改为「学习习惯」。
- 习惯区下方新增**每日一句**卡片：标签、名句、出处与右上角「换一句」。内置 24 条与学习相关的名句（《论语》《荀子》、韩愈、杜甫、陆游、朱熹、诸葛亮、陶渊明、屈原等），按 epoch day 轮换；点一次换下一条，不随机、不重复；日期变化后回到当天条目。
- 习惯数据加载中或失败时，每日一句仍然显示，不跟着习惯卡一起消失。

## 8. 限制

- 底部抖动修复在 Pixel 7 Pro / API 37 模拟器上用帧相等断言验证；用户真机的厂商 ROM 手势策略可能不同，仍建议在真机上滑一次两本书的底部确认。
- 为避免抖动，资料弹窗禁用了整张 sheet 的下滑关闭；关闭入口是顶部按钮、返回键或遮罩。
- 书籍内容为静态离线资料，数量与文案由 `LearningMaterials.kt` 维护；数学公式是纯文本，不渲染分式、根号覆盖线等排版。
- 手动换环只在当前进程内保持，重启后恢复默认环；换环不会写入 Room，也不会改变任务优先级、截止日期或完成状态。
- 悬浮球位置按内容区坐标保存；旋转屏幕后会被重新钳制到新内容区边界内。

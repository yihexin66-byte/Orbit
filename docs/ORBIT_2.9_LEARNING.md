# Orbit Learn 2.9 · 目标合并、学习页与翻卡背单词

2.9 做三件事：把「目标」与「规划」合并成同一页的三个分段；把完整的今日学习与背单词搬到新的「学习」标签；把首页的今日学习收成三行预览，解决「太多划不完」。本轮的单词学习刻意只做「翻卡自评 + 错词重练」，不引入拼写题、选择题、间隔重复排程或发音。

## 导航与页面结构

底部五个标签变为：

| 路由 | 标签 | 内容 |
| --- | --- | --- |
| `orbit` | 星轨 | 双环星图、今日学习三行预览、学习习惯、每日一句、AI 助手 |
| `goals` | 目标 | 「目标 / 任务 / 习惯」三个分段，默认目标 |
| `learning` | 学习 | 今日古诗 / 单词 / 数学全卡、背单词卡、三本书书架 |
| `growth` | 成长 | 等级、任务统计、习惯一致性、目标进度、AI 周复盘 |
| `profile` | 我的 | 账号、头像、同步、主题、数据概览、关于 |

- 原 `planner` 路由与「规划」标签删除；任务页与习惯页不再注册为独立目的地，而是目标路由内的两个分段。
- 分段状态由 `PlannerSegment` 承载，使用 `rememberSaveable` 在 Activity 重建后恢复；默认「目标」。
- 再次点击底部「目标」会把分段重置为「目标」。这样从任务分段离开再点回来，入口行为可预期，也方便设备测试复位。
- 底部标签新增稳定语义标签 `orbit_nav_<route>`（`navTabTag()`）。分段 pill、任务分类 chip 与底部标签复用「目标 / 任务 / 习惯 / 学习」这些中文词，只按文字匹配会同时命中两处；测试统一先按标签路由，再在页内按角色挑选控件。
- 返回键行为不变：其他标签回星轨；目标详情先回目标列表。

## 首页：今日学习三行预览

首页原「今日学习」是两张完整卡加一条今日数学，长诗、例句与公式会把页面拉得很长。2.9 改为固定三行：

- 每行只显示标签（今日古诗 / 今日英语 / 今日数学）、标题与一行摘要；数学行仍带 ∑ 图标。
- 任意一行或「进入学习 →」都打开学习页顶部，不再把首页当阅读器。
- 三行与学习页今日卡、书架 TODAY 卡、书页今日标记读同一个 `LearningViewModel` 状态，设为今日或跨天轮换时四处同步。
- 首页其余部分（星图、节点详情、完成手势、习惯、每日一句、AI 助手）未改动。

## 学习页

`LearningScreen` 是一张 `OrbitLazyScreen`，从上到下：

1. 页头 `学习`。
2. 「今日学习」标题。
3. 今日古诗卡：完整诗题、作者 / 朝代、正文；默认折叠四行，可展开注释与赏析。
4. 今日单词卡：单词、音标、释义；展开显示例句、译文与记忆提示，缺少例句时给出空态与 AI 入口。
5. 今日数学卡：年级、知识点、等宽公式、摘要；展开显示例题、答案与易错提醒。
6. 单词学习卡。
7. 学习书架：唐诗三百首、高中 3500 词、数学讲义三本。
8. 页脚。

今日三张卡与书架里的同名卡片共用同一套展开 / AI 讲解逻辑，区别只是入口从书页换成了学习页顶部。首页不再渲染完整卡，长诗与词条不会撑开星轨页。

## 单词学习

### 选词

- 每轮数量 `dailyTarget` 默认 10，范围 1–50；快捷预设为 5 / 10 / 20 / 30，另有步进器做 ±1。数量按账号保存。
- 自动选词 `WordStudyPlanner.autoSelect` 分三桶，依次取：
  1. 从未学过的词；
  2. 最近一次答「不认识」的词，按上次学习日从早到晚；
  3. 最近一次答「认识」的词，同样按上次学习日从早到晚。
- 同一桶内保持词库顺序，所以一轮仍像顺着课本走，而不是随机抽样。重复词按 id 去重，取满数量即止；词库不够时返回全部可选项。
- 手动选词 `manualSelect` 保留书序、丢弃未知 id，并在 50 处截断。选择器显示「已选 N / 50」，达到上限后不再接受新选择；可按单词拼写或中文释义搜索。

自动选词先于手动的唯一区别是选词来源；回合、作答、结算与进度三条路径完全一致。

### 一轮会话

`WordStudySession` 是一个纯数据状态机：

```text
未翻面 ──reveal()──▶ 已翻面 ──answer(known)──▶ 下一张 / 完成
   │                      │
   └─ answer() 被忽略      └─ 统计认识 / 不认识、正确率
```

- 卡片先只给单词与音标，避免先看释义再自评。未翻面时 `answer()` 直接返回原状态。
- 翻面后出现释义、例句、译文与记忆提示，底部是「认识 / 不认识」。
- 全部答完后进入结算：本轮正确率、认识数、不认识数。全对时只显示鼓励语；有错词时显示「重练错词 N」与「错词会在下一轮自动优先出现」。
- 「重练错词」只拿本轮答「不认识」的词重新开一轮；「再来一组」按当前进度重新自动选词；「完成」清空会话回到学习卡。
- 会话保存在 `WordStudyViewModel` 而不是 sheet 内。关掉弹窗、切到别的标签再回来，学习卡会显示「继续学习 N / M」，不会丢掉半轮进度。
- 每答一张卡就立即写入进度，进程被杀也只丢当前未作答的卡片状态。

### 进度模型

`WordStudyProgress` 只保存每个词的最后一次作答，不保存整段答题历史：

| 字段 | 含义 |
| --- | --- |
| `knownCount` / `unknownCount` | 该词历史累计认识 / 不认识次数 |
| `lastStudiedEpochDay` | 最后一次作答的本地自然日序号 |
| `lastAnswerKnown` | 最后一次是认识、不认识，或从未作答 |

派生指标：

- 今日已学 = `lastStudiedEpochDay == today` 的唯一词数；同一词重练只更新当日结果，不重复计数。
- 累计词数 = 出现过记录的唯一词数。
- 待复习 = 最后一次答「不认识」的词数，它们排在下一轮自动选词的第二桶。
- 今日目标达成时学习卡显示「今日目标已完成，还可以再学一组」，但不会阻止继续学习。

单词学习不写 Room、不发经验、不影响成长页；它只是学习页的本机练习记录。

### 持久化

- 键位：`orbit_learning` 中的 `word_study.<owner>`；`owner` 为当前账号 id，未登录回退 `local`。
- 值：Gson 序列化的 `WordStudyProgress`（记录表 + `dailyTarget`），损坏或为空时回退默认进度。
- 账号切换时 `WordStudyViewModel` 重新加载对应 owner 的进度，并清空正在进行的会话；会话属于开始它的账号。
- Activity 重建、进程重启、切回原账号都能恢复；卸载重装、清除数据或换设备会丢失，云端快照不包含这些记录。

## 已知边界

- 没有发音、拼写题、选择题、例句填空与间隔重复（SM-2 之类）排程；「待复习」只是错词优先，不是复习计划。
- 学习记录只在本机、按账号隔离，不进入云端快照；换设备不同步。
- 每轮与手动选择的硬上限都是 50，数量记忆也只在本机。
- 首页三行预览不展开正文，阅读与 AI 讲解必须进学习页或书架。
- AI 功能仍依赖 `docs/COZE_SETUP.md` 中的 Coze 环境变量；未配置时今日卡与词卡会给出未配置提示。
